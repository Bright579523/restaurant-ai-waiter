================================================================================
📄 เอกสารอธิบาย Data Pipeline (สกัดและจัดตารางข้อมูลเมนูอาหาร Swagat)
================================================================================
วิชา / โครงงาน: ReDi School Final Project - Swagat AI Waiter
จัดทำโดย: Bright
ไฟล์สคริปต์หลักที่เกี่ยวข้อง: generate_csv.py (อยู่ใน scratch folder)
ผลลัพธ์ที่ได้: swagat_menu.csv (157 รายการ, 18 คอลัมน์)
================================================================================

กระบวนการทำ Data Pipeline ในโปรเจกต์นี้เริ่มต้นจากข้อความดิบไร้ระเบียบในเอกสาร PDF
แปลงจนออกมาเป็นฐานข้อมูลตาราง (CSV) ที่สะอาดและพร้อมสำหรับนำไปใช้ทำ RAG มี 9 ขั้นตอนหลัก ดังนี้:

--------------------------------------------------------------------------------
1. Read & Split (การอ่านและแบ่งโครงสร้างหน้า PDF)
--------------------------------------------------------------------------------
- โหลดข้อความดิบ (Raw Text) จากไฟล์ 'extracted_menu.txt' (ซึ่งสกัดมาทีละหน้าจาก PDF ดั้งเดิม)
- ใช้คำสั่ง .split("--- PAGE ") ในการแยกแยะข้อมูลออกตามหน้าของไฟล์ PDF (หน้า 1 ถึง 12)
- ทำให้อัลกอริทึมวิเคราะห์เมนูตามขอบเขตและรูปแบบเลย์เอาต์ของแต่ละหน้ากระดาษได้อย่างถูกต้อง

--------------------------------------------------------------------------------
2. Text Clean-up (การกรองข้อมูลขยะและหัวกระดาษ)
--------------------------------------------------------------------------------
- ใช้ฟังก์ชัน 'is_header_or_metadata()' ตรวจสอบและกรองบรรทัดขยะออกไป
- ลบส่วนหัวกระดาษ ท้ายกระดาษ ลิงก์เว็บไซต์ และคำชี้แจงทั่วไป เช่น
  "Swagat Indian Restaurant", "See MENU & Order", "Online Menu Of" หรือ "Alle Vorspeisen..."
- ป้องกันไม่ให้คำอธิบายเชิงตกแต่งเหล่านี้ไปรบกวนความถูกต้องของเมนูอาหารจริง

--------------------------------------------------------------------------------
3. Regex Match (การใช้ Regex แยกโครงสร้างบรรทัดอาหาร)
--------------------------------------------------------------------------------
- ตรวจสอบเส้นแบ่งระหว่างบรรทัดที่เป็นรายการอาหาร กับบรรทัดที่เป็นคำอธิบายส่วนผสม
- ค้นหาบรรทัดที่เริ่มต้นด้วยตัวเลขและลงท้ายด้วยราคาด้วยนิพจน์ปกติ (Regex Pattern):
  ^(\d+)[.,\s]+(.*?)\s+(\d+,\d{2})$
- แยกข้อมูลทันทีเมื่อตรงเงื่อนไข:
  * m.group(1) -> item_id (รหัสรายการอาหาร)
  * m.group(2) -> name (ชื่อรายการอาหาร)
  * m.group(3) -> price (ราคาสุทธิ แปลงเครื่องหมายจุลภาค , เป็นจุดทศนิยมแบบ float)
- บรรทัดที่ไม่ตรงเงื่อนไขจะถูกเก็บไว้เป็นประโยครอยืนยันเพื่อนำไปทำเป็นคำอธิบาย (Description)

--------------------------------------------------------------------------------
4. Description Merge (การรวมประโยคคำอธิบายหลายบรรทัด)
--------------------------------------------------------------------------------
- เนื่องจากคำอธิบายอาหารในเมนูเยอรมันมักยาวและขึ้นบรรทัดใหม่ สคริปต์จึงตรวจสอบคำลงท้ายบรรทัดก่อนหน้า
- หากบรรทัดก่อนหน้าลงท้ายด้วยคำเชื่อม เช่น 'und' (และ), 'aus' (จาก), 'süß-' (หวาน-)
  หรือบรรทัดใหม่เริ่มต้นด้วยคำว่า 'und Mandeln' (และอัลมอนด์) หรือตัวย่อวงเล็บสารก่อภูมิแพ้ เช่น '(f)'
- ระบบจะนำข้อความเหล่านี้มาเชื่อมต่อรวมกันเป็นคำอธิบายชิ้นเดียวแบบประโยคสมบูรณ์

--------------------------------------------------------------------------------
5. Group Alignment (การจับคู่รายการอาหารกับคำอธิบายอย่างสอดคล้อง)
--------------------------------------------------------------------------------
- ออกแบบกฎการจัดตำแหน่ง (Alignment Rules) แยกเป็น 4 กลุ่มเพื่อแก้ไขเรื่องความไม่ต่อเนื่องของ PDF:
  * Group A (หน้า 1-3): เป็นหน้าเมนูพิเศษตอนกลางวัน ซุป และสลัด ที่คำอธิบายหล่นข้ามหน้า
    ใช้ระบบการดึงข้อความไหลต่อกัน (Flow matching)
  * Group B (หน้า 4-10): หมวดอาหารจานหลักแบบปกติ จับคู่คำอธิบายตรงบรรทัดแบบ 1 ต่อ 1
  * Group C (หน้า 11): หน้า Beilagen & Desserts (เครื่องเคียงและของหวาน)
    สคริปต์จะข้ามรายการ ID 160 และ 161 (ข้าวเปล่า) ซึ่งเป็นข้อยกเว้นไม่มีคำอธิบายในเลย์เอาต์
  * Group D (หน้า 12): เครื่องดื่ม จับคู่คำอธิบายเฉพาะ ID 190 ถึง 194 เมนูอื่นปล่อยคำอธิบายว่าง

--------------------------------------------------------------------------------
6. Tagging & Classification (การวิเคราะห์สารก่อภูมิแพ้และประเภทอาหาร)
--------------------------------------------------------------------------------
- Allergen Extraction: ใช้ Regex ดึงรหัสสารก่อภูมิแพ้ในวงเล็บท้ายคำอธิบาย เช่น (f,g)
  แล้วทำความสะอาดและตรวจสอบเกณฑ์ให้อยู่ในรหัสมาตรฐาน a-m บันทึกเก็บไว้ที่ 'allergen_codes'
- Clean Description: ลบส่วนที่เป็นวงเล็บสารก่อภูมิแพ้ออกไป เพื่อให้เหลือคำอธิบายอาหารที่สะอาดที่สุด
- Category & Meal Type: ใช้ช่วงรหัส ID จำแนกประเภทอาหารย่อย 16 ประเภท และระบุชนิดมื้ออาหาร (meal_type)
  เช่น main, starter, side, dessert, drink

--------------------------------------------------------------------------------
7. Inheritance (การสืบทอดข้อมูลสำหรับเมนูอาหารกลางวัน)
--------------------------------------------------------------------------------
- ในไฟล์ PDF เมนูกลางวัน (Mittagsmenü - ID 500-564) จะถูกระบุชื่ออาหารสั้นๆ ไม่มีคำอธิบายส่วนผสมและรหัสสารแพ้
- สคริปต์แก้ปัญหานี้โดยการสร้างแผนผังเมนูปกติ (IDs < 500) เก็บไว้ในหน่วยความจำ
- ค้นหาชื่ออาหารกลางวันที่ตรงกับเมนูปกติ แล้วสืบทอดรายละเอียด (Description)
  และรหัสสารก่อภูมิแพ้ (Allergens) มาใส่ให้รายการอาหารกลางวันทันที

--------------------------------------------------------------------------------
8. Content Flags & Search Text (การวิเคราะห์ส่วนผสมและการทำดัชนีคำค้น)
--------------------------------------------------------------------------------
- Content Flags: สแกนข้อความหาคีย์เวิร์ดเพื่อระบุการมีอยู่ของวัตถุดิบ (contains_chicken, contains_lamb,
  contains_fish, contains_shrimp, contains_duck, contains_paneer) เป็นค่า boolean (true/false)
  * พิเศษ: หากเป็นเมนูรวมย่าง (Grillplatte) ระบบจะเปิดธงไก่ แกะ และปลา ให้เป็นจริงทั้งหมดโดยอัตโนมัติ
- Search Text: นำ ชื่ออาหาร + หมวดหมู่ + คำอธิบาย + สารแพ้ มารวมกันในช่อง 'search_text'
  เพื่อเตรียมความพร้อมสำหรับป้อนเข้าสู่โมเดล Vector Embedding ในกระบวนการลำดับถัดไป

--------------------------------------------------------------------------------
9. CSV Export (การส่งออกและบันทึกฐานข้อมูลเชิงโครงสร้าง)
--------------------------------------------------------------------------------
- จัดเรียงข้อมูลตามมาตรฐานโครงสร้าง 18 คอลัมน์ที่ระบบ RAG ต้องการ
- บันทึกตารางทั้งหมดลงในพิกัด 'd:\ReDi\Final Project\swagat_menu.csv'
- บังคับการบันทึกเข้ารหัสไฟล์เป็น UTF-8 (UTF-8 encoding) เพื่อรองรับตัวอักษรพิเศษภาษาเยอรมัน
  (เช่น ü, ä, ö, ß) และข้อความภาษาไทย ป้องกันอักษรเพี้ยนหรือพัง
