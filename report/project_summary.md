## 1. 🌟 ภาพรวมและแนวคิดโปรเจกต์

> [!NOTE]
> **ReDi Restaurant AI Waiter** คือระบบจำลอง **"บริกรอัจฉริยะ (AI Waiter)"** สำหรับร้านอาหารอินเดีย ReDi Restaurant ในเมืองแฟรงก์เฟิร์ต ประเทศเยอรมนี 
> ระบบสามารถช่วยแนะนำรายการอาหาร เครื่องดื่ม หรือของหวานให้ลูกค้าผ่านการพิมพ์คุยภาษาง่าย ๆ (ไทย, อังกฤษ, เยอรมัน) โดยพิจารณาจากเงื่อนไขเฉพาะตัวของลูกค้า เช่น งบประมาณ, เมนูมังสวิรัติ (Vegetarian), เมนูเจ (Vegan), อาหารแพ้ (Allergens) หรือความเผ็ด/ส่วนผสมที่ต้องการเลี่ยง

### 💡 ตัวอย่างคำถามที่ระบบตอบได้อย่างแม่นยำ:
* *"อยากกินแกงเผ็ดที่เป็นไก่ ราคาไม่เกิน 17 ยูโร"*
* *"Ich möchte ein vegetarisches Gericht ohne Milch/Laktose"* (ต้องการจานเจ/มังสวิรัติที่ไม่มีนม/แลคโตส)
* *"Recommend a popular side dish under 5 euros that has cheese"*

## 2. ⚙️ สรุปขั้นตอนการพัฒนาใน 5 นาที

เพื่อให้เห็นภาพง่ายที่สุด กระบวนการพัฒนาถูกแบ่งออกเป็น **4 ขั้นตอนหลัก** ดังนี้ครับ:

```
┌─────────────────┐     ┌──────────────────────┐     ┌──────────────────┐     ┌─────────────────┐
│ 1. ดึงและกรองข้อมูล │ ──▶ │ 2. จัดหมวดหมู่/ป้ายกำกับ │ ──▶ │ 3. ทำ Embedding   │ ──▶ │ 4. ค้นหาและตอบ  │
│ จาก PDF เมนูร้าน  │     │ ลงฐานข้อมูล CSV      │     │ เก็บไว้ในเครื่อง  │     │ ผ่านเว็บแอป     │
└─────────────────┘     └──────────────────────┘     └──────────────────┘     └─────────────────┘
```

1. **สกัดข้อความ (PDF parsing):** อ่านไฟล์เมนู PDF ทั้งหมด 14 หน้า และคัดแยกเอาเฉพาะหน้า 1-12 ซึ่งเป็นรายการอาหารมาใช้งาน ส่วนข้อมูลอื่น ๆ คัดออกเพื่อความแม่นยำ
2. **สร้างฐานข้อมูลคุณภาพสูง (Structured CSV):** นำรายการอาหารที่ได้มาจัดเป็นตาราง Excel/CSV พร้อมสร้าง **Dietary Tags (ป้ายกำกับข้อมูล)** เช่น เมนูนี้มีไก่/แกะ/ปลาหรือไม่? เป็นมังสวิรัติหรือไม่? มีสารก่อภูมิแพ้ตัวไหนบ้าง?
3. **จัดทำระบบค้นหาตามความหมาย (Vector Cache Indexing):** แปลงคำอธิบายเมนูอาหารทั้งหมดเป็นรหัสเวกเตอร์ตัวเลข (Embedding) ผ่านโมเดลภาษา เพื่อให้ระบบสามารถค้นหาเมนูตามความหมายได้ (เช่น พิมพ์ว่า "ชีสอินเดีย" ระบบจะแนะนำเมนูที่มีคำว่า "Paneer" ได้ทันที)
4. **สร้างหน้าตาแอปพลิเคชัน (Streamlit UI + RAG Agent):** นำระบบค้นหามาเชื่อมโยงกับโมเดลสมองกล AI (Groq Llama 3.3) และสร้างหน้าเว็บแอปพลิเคชันผ่าน Streamlit โดยมีแผงตัวกรองและฟีเจอร์ช่วยอำนวยความสะดวกใน Sidebar ได้แก่ **ปุ่มรีเฟรชล้างประวัติการแชท (Clear Chat)** และ **ปุ่มดาวน์โหลดไฟล์ PDF เมนูร้านอาหารต้นฉบับ**

## 4. 🧠 เจาะลึกกระบวนการทำงานแบบละเอียด

### 4.1 การสกัดและทำความสะอาดข้อมูล (Data Extraction & Cleaning)
* **การกรองข้อมูลส่วนเกิน:** เนื่องจากเมนู PDF หน้า 13-14 เป็นตารางอ้างอิงสารก่อภูมิแพ้และข้อมูลที่ตั้งร้าน ระบบจึงใช้เฉพาะหน้า 1-12 เพื่อความสะอาดของ RAG Context
* **การแก้ไขปัญหาข้อความเพี้ยน (Cross-page text shift):** บ่อยครั้งที่คำอธิบายเมนูแถวล่างสุดของหน้าแรก ดันกระโดดไปอยู่บนสุดของหน้าถัดไป ระบบได้ทำการเขียน Logic เพื่อดึงข้อความเหล่านั้นกลับมารวมกับรายการอาหารเดิมโดยอัตโนมัติ ทำให้ได้ข้อมูลที่สมบูรณ์ 100%

### 4.2 การติดป้ายกำกับเมนูอาหาร (Smart Labeling)
เพื่อให้ระบบตอบคำถามเรื่องข้อจำกัดด้านอาหารได้แม่นยำ จึงมีการสร้างคอลัมน์พิเศษใน [redi_menu.csv](file:///d:/ReDi/Final%20Project/redi_menu.csv) ดังนี้:
* **ประเภทอาหาร (Meal Type):** ระบุประเภท เช่น `main` (จานหลัก), `starter` (ซุป/สลัด), `side` (โรตี/ข้าวกระเทียม), `dessert` (ของหวาน), `drink` (เครื่องดื่ม)
* **ตัวกรองมังสวิรัติและเจ (Veg/Vegan):** 
  * `is_vegetarian` เป็นจริง เมื่อไม่มีเนื้อสัตว์ทุกประเภท
  * `is_vegan_possible` เป็นจริง เมื่อเป็นมังสวิรัติและ **ไม่มีส่วนผสมของนม เนย ชีส ครีม โยเกิร์ต หรือน้ำผึ้ง**
* **ตัวกรองสารก่อภูมิแพ้ (Allergen Codes):** บันทึกรหัสย่อมาตรฐาน เช่น `a` (กลูเตน/แป้งสาลี), `f` (นม/แลคโตส), `g` (ถั่วต่าง ๆ) เพื่อคัดแยกเมนูที่เป็นอันตรายกับผู้ใช้บางรายออกไปได้อย่างเด็ดขาด

---

### 4.3 ระบบค้นหารูปแบบผสมผสาน (Hybrid Retrieval Engine)

> [!IMPORTANT]
> **ทำไมระบบนี้ถึงไม่ใช้ Vector Search หรือ Database กรองข้อมูลอย่างใดอย่างหนึ่ง?**
> * **ถ้าใช้แค่ Keyword / Vector Search:** เมื่อผู้ใช้สั่งว่า *"ขอเมนูเจ ราคาไม่เกิน 12 ยูโร"* ระบบ Vector Search มักจะดึงเมนูที่น่าอร่อยตามความรู้สึก แต่มีราคา 14 ยูโร หรือมีเนื้อสัตว์ปะปนมาด้วย เนื่องจากมองข้ามเงื่อนไขที่เป็นกฎเกณฑ์ตายตัว
> * **ถ้าใช้แค่การกรองข้อมูล (Database Filter):** จะไม่สามารถหาอาหารตามความหมายกว้าง ๆ ได้ เช่น สั่งว่า *"ขอเมนูเผ็ด ๆ ร้อน ๆ"* หรือ *"เมนูที่กินแล้วสดชื่น"* เพราะไม่มีคอลัมน์เก็บข้อมูลเหล่านี้ไว้

**ระบบค้นหาของเราจึงรันในแบบ "Hybrid" แบ่งเป็น 2 ขั้นตอน:**

```
1. กรองข้อมูล (Metadata Filter)        2. จัดอันดับความคล้ายคลึง (Semantic Rank)
   กรองเมนูที่ไม่ตรงเงื่อนไขทิ้งทันที          นำเมนูที่ผ่านเกณฑ์มาคำนวณหาความใกล้เคียง
   เช่น คัดเฉพาะเมนูเจ และราคา <= 12        ของความต้องการ ผ่าน Cosine Similarity
   (ผลลัพธ์ผ่านเกณฑ์ 10 เมนู)             (แสดงเมนูที่เหมาะสมที่สุด 3 อันดับแรก)
```

---

### 4.4 การแปลเจตนาด้วยโมเดลภาษา (Intent Parsing & Context Generation)
1. **Pydantic Schema:** กำหนดโครงสร้างตัวกรองที่ชัดเจน เช่น กำหนดให้งบประมาณต้องเป็นข้อมูลตัวเลขทศนิยม (`float`), สารก่อภูมิแพ้เป็นรายการตัวอักษรย่อ (`list[str]`)
2. **Groq Llama 3.3-70B:** โมเดลจะอ่านข้อความที่ผู้ใช้พิมพ์คุย แล้วดึงตัวกรองต่าง ๆ ออกมาใส่ในแบบฟอร์ม JSON โดยอัตโนมัติ ทำให้ระบบ Python นำไปกรองข้อมูลในตารางต่อได้ทันที
3. **พนักงานเสิร์ฟอัจฉริยะ (RAG Response):** เมื่อระบบค้นพบรายการเมนูที่ตรงใจแล้ว โมเดล Llama จะนำรายละเอียดอาหารมาเรียบเรียงใหม่เป็นประโยคแนะนำสไตล์บริกรที่สุภาพ โดย **ใช้ภาษาเดียวกับที่ผู้ใช้ทักแชทเข้ามาโดยอัตโนมัติ**

## 7. 🚀 วิธีการติดตั้งและเริ่มใช้งาน

เพื่อความสะดวกในการติดตั้งโปรเจกต์นี้ในเครื่องคอมพิวเตอร์ของคุณ โปรดทำตามขั้นตอนเหล่านี้:

### 7.1 การดาวน์โหลดเครื่องมือที่จำเป็น (Dependencies)
เปิดโปรแกรม Terminal หรือ Command Prompt ในโฟลเดอร์ของโปรเจกต์ แล้วรันคำสั่ง:
```bash
pip install pandas numpy sentence-transformers scikit-learn
pip install groq pydantic python-dotenv streamlit pypdf
```

### 7.2 การตั้งค่าความปลอดภัยและ API Key
1. คัดลอกไฟล์ตัวอย่างเพื่อสร้างไฟล์ตั้งค่าของตัวเอง:
   ```bash
   copy .env.example .env
   ```
2. เปิดไฟล์ `.env` ที่สร้างขึ้นใหม่ด้วย Text Editor ใดก็ได้ แล้วใส่ API Key ของ Groq ที่ได้มา:
   ```env
   GROQ_API_KEY=gsk_xxxxxxxxxxxxxxxxxxxx
   ```

### 7.3 เริ่มต้นระบบคำนวณและเปิดแอปพลิเคชัน
1. **สร้างไฟล์แคชเวกเตอร์ภาษา (ทำเพียงครั้งแรกครั้งเดียว):**
   ```bash
   python embeddings/build_embeddings.py
   ```
   *รอจนขึ้นข้อความ `Vector cache saved to embeddings/menu_embeddings.pkl`*
2. **รันหน้าเว็บ Streamlit:**
   ```bash
   streamlit run app/app.py
   ```
   *ระบบจะเปิดเบราว์เซอร์หน้าจอแอปพลิเคชันที่ `http://localhost:8501` โดยอัตโนมัติ*
